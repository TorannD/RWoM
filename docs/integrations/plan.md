# RWoM Integrations extraction plan

**Goal:** move existing optional third-party integrations into a separately installable RimWorld 1.7 mod without changing gameplay or losing saved data.
**Architecture:** RWoM Core owns neutral extension contracts; RWoM owns gameplay, DLC support and general safety fixes; RWoM Integrations owns third-party adapters. Add a Core contract only when an adapter needs it. Do not create a generic plugin framework speculatively.
**Tech stack:** existing C#/.NET 10, Harmony, RimWorld XML patch operations, existing pwsh regression runner.
**Approval:** user approved the three-part structure and requested implementation and a separate Trello list on 2026-11-05.
**Queue:** [RWoM board](https://trello.com/b/v1iMNpjW/rwom), list `RWoM Integrations — выделение совместимости`.

## Constraints and rollback

- v1.6, third-party installations, user ModsConfig and original saves remain unchanged.
- First package lives at `TorannMagic.Integrations/`, matching the nested Core layout. It must not be loaded recursively as part of the parent mod.
- Package ID: `huginn.rwom.integrations`; name: `RWoM Integrations`. English About and documentation.
- RWoM is required; each third-party target is optional. Core becomes an explicit dependency only if the package actually consumes its API.
- Preserve defNames, namespaces, assembly identities and Scribe keys for persisted objects. Moving a source file is not proof a saved type can still resolve.
- Transfer ownership atomically at release: remove old delivered files and install new files from a reviewed manifest. Never ship two active copies of an adapter.
- An old RWoM release plus new Integrations package must be rejected/documented as unsupported, or guarded against duplicates, before public release.
- Rollback restores matched RWoM/Integrations versions from backup. Do not silently disable/remove integrations on an existing save. Component-bearing integrations may require the package to remain enabled.
- Full regression only at substantial milestones/delivery, with the existing 24 exclusions explicitly reported. No graphical multiplayer acceptance claim from headless tests.
